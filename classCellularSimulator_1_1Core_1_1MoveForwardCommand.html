Executes the move forward command to relocate the cell.

Attempts to move the cell one tile forward in the direction it is currently facing. The movement only occurs if the target tile is valid (within bounds) and empty (no other cell occupies it). If the target tile is occupied or invalid, the command fails silently and the cell remains in place.

Parameters
SimReference to the simulator environment
AgentReference to the cell executing this command
Note
Operation fails silently if target tile is invalid or occupied
Cell direction determines the forward movement vector
No energy cost is associated with movement
